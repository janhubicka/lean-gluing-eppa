# Auxiliary lemma index: reusable mathematics

This page is a selective index of genuinely reusable lemmas, not a
line-by-line dump of every Lean declaration. Import the module named
in the left column or `import GluingEPPA`.

## General closed structures and homomorphism-embeddings

| Declaration | Content |
| --- | --- |
| `UnaryFreeDecomposition` | Two proper closed sides, local relations, no crossing complete unary fibres |
| `IsIrreducible` | Absence of a free decomposition |
| `inducedRelations`, `inducedUnary` | Induced subtype interpretation |
| `inducedUnary_full` | On a closed subtype, the whole ambient fibre is retained |
| `Tree.ExactUnaryEmbedding` | Injective relation-reflecting map, exact full-fibre equality |
| `Tree.UnaryHomEmbedding` | Maps exact on all closed irreducible tests; composable |
| `Tree.UnaryHomEmbedding.comp` | Composition of such maps |
| `unaryClosure_irreducible` | The closure generated by one vertex is irreducible |
| `Tree.UnaryHomEmbedding.out_eq` | Local exactness forces full unary-fibre equality |
| `Tree.UnaryHomEmbedding.image_closed` | Images of closed subsets remain closed |

The generated-closure lemma is surprisingly useful outside EPPA.
It is valid even with infinitely many points or labels,
branching output fibres, cycles and empty fibres.

old source to have a free cut.
